

# Claude_AISolutions_Business

A working collection of Claude prompts, hands-on exercises, and mini-projects
used to learn agentic engineering concepts — sub-agents, hooks, headless
Claude, MCP servers, and CI integration.

## Contents

- `Day2_Handson/`, `Day3/`, `Delivery_hands_day5/` — daily hands-on exercises
- `PRompts/`, `Enhancmenet _Prompts/` — prompt collections
- `backend-agent-lab/`, `taskflow-ops/` — mini-project scaffolds
- `Tier 1/2/3 (*).md` — tiered exercise sets, basic to advanced
- `production.md`, `simple-prompts-cartsvc.md` — worked examples
